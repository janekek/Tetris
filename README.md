# Tetris (Java, From Scratch)

A fully functional implementation of the classic **Tetris** game, developed entirely in Java — built from the ground up without any external libraries or frameworks.

This project represents my **first Java project**, created between **April and May 2022**, and serves as a foundational milestone in my journey into programming and software development.

---

## Overview

This project is a recreation of Tetris, focusing on understanding core programming concepts through practical implementation. Every aspect of the game — from rendering and game logic to input handling — was implemented manually.

The goal was not just to replicate gameplay, but to deeply understand how such a system works internally.

* **Built completely from scratch**

  * No game engines
  * No external libraries
  * No frameworks
* Pure Java implementation

---

## Technical Details

* Classic Tetris gameplay mechanics
* Object-oriented design
* Game loop and timing logic
* Grid-based rendering logic
* State based
* Event handling
