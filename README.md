# Tetris (Java, From Scratch)

A fully functional implementation of the classic **Tetris** game, developed entirely in Java — built from the ground up without any external libraries or frameworks.

This project represents my **first Java project**, created between **April and May 2022**, and serves as a foundational milestone in my journey into programming and software development.

---

## Overview

This project is a complete recreation of Tetris, focusing on understanding core programming concepts through practical implementation. Every aspect of the game — from rendering and game logic to input handling — was implemented manually.

The goal was not just to replicate gameplay, but to deeply understand how such a system works internally.

---

## Key Highlights

* **Built completely from scratch**

  * No game engines
  * No external libraries
  * No frameworks
* Pure Java implementation
* Focus on fundamental programming concepts and problem-solving

---

## Features

* Classic Tetris gameplay mechanics
* Real-time piece movement and rotation
* Line clearing system
* Collision detection
* Score tracking
* Game loop and timing logic
* Keyboard input handling

---

## Technical Details

This project was developed with an emphasis on learning and implementing core concepts, including:

* Object-oriented design
* Game loop architecture
* Grid-based rendering logic
* State management
* Event handling (keyboard input)
* Basic algorithmic problem solving

All rendering and logic are handled manually using standard Java capabilities, without relying on external abstractions.

---

As my first Java project, this implementation was an exploration into how complex interactive systems can be built from simple building blocks. The intention was to avoid “black box” solutions and instead gain a clear understanding of every component involved.

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/janekek/Tetris.git
   ```

2. Navigate into the project directory:

   ```bash
   cd Tetris
   ```

3. Compile and run using Java:

   ```bash
   javac Main.java
   java Main
   ```

*(Adjust the entry file if necessary depending on the project structure.)*
